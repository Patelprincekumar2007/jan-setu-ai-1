# Data Directory

This directory is reserved for local datasets, open-data schemas, and ground-truth baseline files used in future phases:
- `census/` (Planned: Open Census baseline demographic indicators)
- `infrastructure/` (Planned: Public asset registries)
- `schemes/` (Planned: Official scheme guidelines for RAG indexing)
- `chroma/` (Planned: Vector store persistence)

*Note: No production government data or unverified claims are stored here.*
